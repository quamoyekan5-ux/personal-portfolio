# Olamzy_Graphics Portfolio

A modern, dark-themed personal portfolio website for **Quam Oyekan Alani (aka Olamzy_Graphics)**. This project showcases graphic design, frontend development, and web development skills through a polished portfolio landing page.

## Overview

The portfolio includes a hero section, about section, skills, services, projects, testimonials, contact section, and smooth interactive UI features like theme switching, animated cursor, scroll progress, and a particles background.

## Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Remix Icon

## Features

- Responsive portfolio layout
- Light / dark theme toggle
- Animated page loader
- Smooth scroll navigation with active section highlighting
- Typing text animation for roles
- Particle background effect on the hero section
- Interactive hover effects and floating badges
- Contact information and social links integration

## Project Structure

- `index.html` — Main portfolio landing page
- `contact.html` — Contact page layout
- `olamzy_portfolio.html` — Alternate portfolio page
- `style.css` — Styles and theme definitions
- `main.js` — Page interactions, animations, and UI behavior
- `script.js` — Duplicate script file (same portfolio behavior logic)
- `Assets/` — Images, icons, and media resources used by the site

## How to Use

1. Open the project folder in your code editor.
2. Open `index.html` in your browser to view the portfolio.
3. For local development, use a live server extension or a simple local HTTP server.

## Live Preview

To preview locally, you can use the VS Code Live Server extension or run a simple local server such as:

```bash
npx http-server .
```

Then visit:

```text
http://localhost:8080/index.html
```

## Customize

- Update your name, bio, and links in `index.html`
- Replace profile image and project images in the `Assets/` folder
- Adjust colors and typography in `style.css`
- Modify animation behavior in `main.js`

## Notes

- `main.js` contains the core JavaScript logic for UI effects.
- `script.js` appears to be a copy of the same main script.
- If you only need one script file, you can remove or ignore the duplicate.
